Как пользоваться Совой

Сова слушает твои аккаунты Telegram, и Яндекс Станция читает вслух сообщения от тех, кого ты выбрал: «Кристофер, тебе пишет Ева: текст». Настройка один раз, по порядку:

1. Подключить Telegram

Telegram пускает сторонние программы только по ключам разработчика. Получить их бесплатно и один раз — потом с ними можно добавить сколько угодно аккаунтов.

  1. Открой my.telegram.org.
  2. Введи номер телефона в международном формате (+79991234567) и нажми Next. Код придёт в сам Telegram (чат «Telegram»), не по СМС.
  3. Открой API development tools. Если ключи уже создавались, сразу увидишь App api_id и App api_hash — бери их.
  4. Иначе заполни форму: App title — любое, например Sova; Short name — 5–32 латинские буквы, например sovaapp; URL и Description пустые; Platform — Desktop. Нажми Create application.
  5. Скопируй App api_id (число) и App api_hash (32 символа) в Сову → «Подключить Telegram».

Если не выходит:

  • Пишет просто ERROR при создании — это частая беда сайта. Подожди 10–30 минут и повтори, попробуй другой браузер или режим инкогнито, выключи или наоборот включи VPN.
  • Сайт не открывается — попробуй через VPN.
  • Ключи никому не показывай: по ним можно действовать от имени твоей программы.
2. Добавить аккаунт
  1. В блоке «Аккаунты» нажми + аккаунт.
  2. Подпись — как Алиса будет называть этот аккаунт («Кристофер», «Работа»). Телефон — номер аккаунта.
  3. Введи код, который пришёл в Telegram. Если стоит облачный пароль (двухэтапная проверка) — введи и его.
  4. Зелёная точка — аккаунт слушается. Можно добавить несколько аккаунтов теми же ключами.

Сова только читает входящие, ничего не пишет и не отмечает прочитанным. В списке устройств Telegram она появится как новый сеанс — его можно завершить там в любой момент.

3. Кого слушать
  1. Нажми на аккаунт — блок переключится на его задачи.
  2. Логин — @username человека (видно в его профиле). Имя — как Алиса его назовёт: «Ева», «Шеф».
  3. Тумблер у задачи временно выключает её, ✕ удаляет. «‹» — назад к аккаунтам.

Ловятся сообщения и в личке, и в группах, где пишет этот человек. Ссылки Алиса заменит словом «ссылка», вместо фото скажет «фото».

4. Подключить колонку
  1. Мак и Яндекс Станция должны быть в одной Wi-Fi сети (не гостевой).
  2. Нажми «Подключить колонку» → «Открой страницу Яндекса» и войди в аккаунт, к которому привязана станция.
  3. После входа браузер откроет пустую страницу. Скопируй весь адрес из адресной строки (в нём есть access_token=) и вставь в поле, нажми «Подключить».
  4. Если macOS спросит «Разрешить Сове искать устройства в локальной сети» — нажми Разрешить, иначе колонка не найдётся.
  5. Нажми «Проверить колонку» — Алиса скажет тестовую фразу.

Если не находит станцию: проверь, что VPN выключен и мак в той же сети. Можно вписать IP станции вручную (его видно в настройках роутера среди устройств). Если запретил доступ к локальной сети — включи его в Системные настройки → Конфиденциальность и безопасность → Локальная сеть → Сова. Если станций несколько, Сова берёт первую.

Прочее
  • Сова живёт в меню-баре (иконка совы вверху справа). Закрытое окно не выключает её, выйти — через меню.
  • «Запускать при входе» в том же меню — чтобы стартовала сама после перезагрузки.
  • «Слушаю» выключает озвучку целиком, ползунок 🔊 — громкость, с которой Алиса читает.
  • Все настройки и сессии хранятся только на этом маке: ~/Library/Application Support/Sova.
