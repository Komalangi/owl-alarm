# Сова

Приложение-часы для macOS: слушает несколько Telegram-аккаунтов, и Яндекс Станция читает вслух сообщения
от выбранных людей. Фраза всегда одна: «<Аккаунт>, тебе пишет <имя>: <текст>».
Пример: «Кристофер, тебе пишет Остро: глянь отчёт».

- Ловятся входящие и в личке, и в любых группах, где пишет отслеживаемый человек.
- Ссылки заменяются словом «ссылка», эмодзи выкидываются, длинный текст обрезается до ~280 знаков.
- Вместо медиа без подписи Алиса говорит «фото», «голосовое сообщение» и т. п.
- Сообщения идут в очередь, Алиса не перебивает сама себя.

## Как пользоваться

`/Applications/Сова.app` — небольшое окно-часы, живёт в меню-баре (иконка совы). Окно из трёх блоков:

1. **Часы.**
2. **Колонка:** тумблер «Слушаю» (вкл/выкл озвучку целиком), громкость 🔊, «Проверить колонку».
   Если колонка не подключена, здесь появится кнопка «Подключить колонку» с инструкцией:
   открыть страницу Яндекса, войти в аккаунт станции, скопировать адрес из строки браузера и вставить его в поле.
   Токен сохраняется в `.env`. Мак и станция должны быть в одной Wi-Fi сети.
3. **Аккаунты.** Нажми на аккаунт — блок переключится на его задачи: логин того, кого отслеживаем (@username),
   и имя, которым Алиса его называет. Тумблер у задачи включает и выключает её, «‹» возвращает к аккаунтам.
   Новый аккаунт: «+ аккаунт», подпись (как Алиса называет аккаунт), телефон, код из Telegram, пароль 2FA.
   Подпись аккаунта меняется кликом по названию в шапке задач.

Настройки лежат в `watch.json`, сессии Telegram в `sessions/` (дают доступ к аккаунтам, никому не передавать;
оба в `.gitignore`).

## Сборка и запуск без приложения

```bash
bash build_app.sh                      # собрать Сова.app и положить в /Applications
.venv/bin/python main.py serve         # только сервис, интерфейс на http://127.0.0.1:7781
.venv/bin/python main.py say "привет"  # проверить колонку
.venv/bin/python main.py devices       # станции аккаунта Яндекса и их IP
```

`.env`: `TG_API_ID`, `TG_API_HASH` (my.telegram.org), `YANDEX_TOKEN`
(https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d),
по желанию `STATION_IP` и `STATION_DEVICE_ID`. Компьютер и станция должны быть в одной Wi-Fi сети.
Лог: `sova.log`, лог приложения `~/Library/Logs/Sova.log`.
